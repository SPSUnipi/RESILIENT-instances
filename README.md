This repo denotes the umbrella repository to contain the instances to test the performance of SMS++ on different instances generated using different models. The repo contains the following folders:
- cases-pypsa-eur: This folder contains the procedure to compare the performance offered by SMS++ on instances generated using the PyPSA-Eur model.
- cases-plan4res: This folder contains the procedure to compare the performance offered by SMS++ on instances generated using the Plan4Res findings.

Each folder contains a README.md file that describes the procedure to compare the performance of SMS++ on the respective instances.
